# Flux TV — version améliorée

Site Flask indépendant pour gérer des chaînes et leurs flux autorisés.

Fonctions :
- accueil moderne et responsive
- liste des chaînes actives
- lecteur vidéo réel
- prise en charge HLS (.m3u8) avec hls.js
- activation/désactivation
- dates de début/fin
- heures de diffusion
- jours de la semaine
- ajout, modification et suppression
- statistiques de vues
- statistiques par pays
- administration protégée
- `templates/base.html` avec emplacements publicitaires

Variables Render :
`SECRET_KEY`
`ADMIN_EMAIL`
`ADMIN_PASSWORD`

Important : utiliser uniquement des flux que vous avez le droit de diffuser.
